# Contributing

Contributions to the public firmware source and user-facing documentation are welcome. Keep changes focused and describe the board and observed behavior clearly.

## Report a hardware issue

Use the **Hardware bug report** issue form. Include the PCB revision, MCU marking, LCD controller if known, firmware configuration, and the steps to reproduce the issue. Add expected and observed behavior, relevant supply/input conditions, and a photo if it helps explain the problem.

Do not post your MCU's private 96-bit UID or an ST-Link serial number. They are not needed to assess a report. Do not attach unrelated private files.

## Scope

This public contribution area is for firmware source and user or build documentation. Do not add tests, generated build outputs, local reports, or private working files to a contribution.
